Data Science Pipeline

Fourteen stages, problem framing through monitoring. Your own roadmap, cleaned up and laid out to study from, or print and keep at your desk.

Route map

  • Find hidden patterns
  • Detect anomalies
  • Build a recommendation
  • Forecast the future

05

Data Cleaning, Preprocessing

  • Remove duplicates
  • Missing values: MCAR, MAR, MNAR
  • Imputation: mean, median, mode, KNN, regression, MICE
  • Correct errors
  • Fix data types
  • Remove inconsistencies
  • Handle outliers: IQR, Z-score, DBSCAN, isolation forest
  • Text: tokenize, lowercase, remove stopwords, lemmatize
  • Images: resize, normalize pixel values, augment
06

  • Encoding or embedding
  • Scaling
  • Normalization
  • Standardization
  • Feature extraction
  • Feature creation
  • Dimensionality reduction: PCA, t-SNE, UMAP
  • Feature selection: PCA, LASSO, tree-based
Numeric, distance or gradient based
SVM, KNN, PCA, neural nets, logistic regression need StandardScaler or MinMax
Tree models
Random forest, XGBoost, decision tree need no scaling
Categorical, binary
Label encoding
Categorical, nominal
One-hot encoding
07

Data Splitting

  • Train
  • Test
  • Validation
  • Typical ratios: 70 / 15 / 15, or 80 / 20
Leakage ruleFit scalers, encoders, and imputers on the training set only, then apply them to test. Never the reverse. Same rule for feature selection and target encoding.
Small datasetUse k-fold, stratified k-fold, or time series cross-validation instead of a single split

09

Model Training

Before anything elseFit a baseline: mean prediction for regression, majority class for classification. The real model has to clearly beat it.
Regression
Linear regression, Ridge, Lasso, SVR, random forest, XGBoost, decision tree, LightGBM, CatBoost
Classification
Logistic regression, SVM, KNN, decision tree, random forest, XGBoost, LightGBM, CatBoost
Clustering
K-means, DBSCAN, Gaussian mixture
Forecasting
ARIMA, Prophet, LSTM
NLP
BERT, RoBERTa, GPT, TF-IDF
Computer vision
CNN, ResNet, ViT, YOLO
Baseline→ Select algorithm→ Initialize parameters→ Fit model→ Calculate training loss→ Validate with CV→ Save checkpoints→ Compare models→ Stack or blend top models
10

Model Evaluation

Regression
MAE, MSE, RMSE, RMSLE, R squared, adjusted R squared, MAPE
Visualize: predicted vs actual, residual plot, error distribution
Classification
Confusion matrix, accuracy, precision, recall, specificity, F1, ROC-AUC, MCC, log loss, PR curve
Visualize: ROC curve, confusion matrix, calibration curve
Clustering
Silhouette score, Davies-Bouldin index, Calinski-Harabasz index, inertia
Forecasting
RMSE, MAE, sMAPE, MASE
Close the loopCheck the result against the question framed in Problem Understanding. A strong RMSE means nothing if it doesn't answer the original question.

14

Monitoring

  • Log errors
  • Explain predictions: SHAP, LIME, permutation importance
  • Monitor for bias
  • Data drift: input distribution shift, checked with PSI or the KS test
  • Concept drift: the relationship between inputs and target shifts, usually the real trigger to retrain
